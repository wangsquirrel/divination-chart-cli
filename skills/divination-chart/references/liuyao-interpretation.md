# 六爻解读框架

## 1. 取用神

先用问题语义决定主要观察对象，不要见到某个六亲旺就倒推问题。

| 问题焦点 | 常见主要观察 |
| --- | --- |
| 自身状态、能否承担、行动方 | 世爻 |
| 对方、合作方、目标方 | 应爻 |
| 文书、合同、消息载体、房屋、学业、长辈 | 父母 |
| 工作职位、规则压力、诉讼、疾病或风险 | 官鬼 |
| 钱财、资产、交易收益、资源 | 妻财 |
| 结果产出、子女、缓解、医药、脱险 | 子孙 |
| 同辈、竞争者、合伙分利、费用损耗 | 兄弟 |

这些是常见映射而非机械定律。感情、健康、诉讼等问题常需要同时观察世应和多个六亲；说明采用哪一种映射以及原因。

## 2. 判断强弱与关系

五行生序：

```text
木 → 火 → 土 → 金 → 水 → 木
```

五行克序：

```text
木 → 土 → 水 → 火 → 金 → 木
```

按以下顺序判断：

1. 月建是否同类、生扶、泄耗或克制用神/世爻。
2. 日辰是否同类、生扶、泄耗或克制，并是否与爻支冲合。
3. 用神是否旬空、伏藏，是否得到月日或动爻扶助。
4. 世应之间谁生谁、谁克谁，哪一方发动。
5. 动爻对用神、世爻的生克，以及它化出的五行和六亲是助力还是阻力。

常用地支关系：

- 六冲：子午、丑未、寅申、卯酉、辰戌、巳亥。
- 六合：子丑、寅亥、卯戌、辰酉、巳申、午未。

“逢冲”“逢合”要结合旺衰和动静解释。不要仅凭一组冲合直接判吉凶。旬空通常表示作用暂弱、尚未落实或需要条件触发，不等于永久不存在。

## 3. 分析动变

- 无动爻：以本卦、用神、世应和月日为主，倾向描述现状稳定或变化动力不足。
- 单动爻：把该爻作为主要变化线索，比较本爻与变爻的六亲、五行和对用神的作用。
- 多动爻：先保留直接作用于用神、世爻或应爻的链条，再解释其他动爻；避免逐爻断语相互抵消。
- 伏神：说明目标信息未显、受压或需条件引出；同时检查飞神与月日，不把“伏”直接等同于无望。

特殊卦型只作结构提示：

- 六合：偏向聚合、黏连、稳定，也可能是拖延或难解。
- 六冲：偏向变化、冲散、反复，也可能是打破僵局。
- 游魂：偏向游移、不安、在外或难定。
- 归魂：偏向回返、收束、回到旧模式。

## 4. 使用六神

只在核心证据成立后补充象意：

- 青龙：喜悦、助力、礼仪、顺遂。
- 朱雀：言语、消息、文书、争辩。
- 勾陈：牵连、迟滞、土地、旧事。
- 腾蛇：疑虑、反复、虚惊、隐晦。
- 白虎：压力、冲突、损伤、强硬。
- 玄武：隐情、欺瞒、私下、流失。

六神是修饰语，不是独立结论。神煞同理。

## 5. 形成结论

把结论写成“证据 → 推断 → 条件”：

```text
证据：用神获月建生扶，但自身旬空，且应爻发动来克世。
推断：事情有外部条件，却暂未落实，对方掌握更多主动权。
条件：若后续填空并减少对方制约，趋势才可能转强。
```

区分三种内容：

- 盘面事实：可直接指向 JSON 字段。
- 流派推断：根据传统规则得出，允许存在不同解释。
- 现实建议：应能独立于占卜成立，例如核实合同、保留预算、直接沟通。

避免绝对化语言、恐吓性断语和无法验证的精确承诺。
