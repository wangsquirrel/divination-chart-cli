# 六爻解读：取用、月日与动变

采用《增删卜易》纳甲框架。以下是便于复核的操作规则，不是预测有效性的证明。
章节依据与分歧见[来源索引](liuyao-source-map.md)；涉及“何时”时读取
[应期规则](liuyao-timing.md)。规则编号用于把推断与依据对应，不能替代 JSON 字段证据。

## 1. 取用神（Y1）

先明确谁问、问谁、问什么、截至何时；不能因某爻旺而倒推问题。

| 问题对象 | 主要观察对象 | 必须区分 |
| --- | --- | --- |
| 自身、行动能力 | 世爻 | 世是问卦者，不必就是事情的用神 |
| 对方、交易或合作对象 | 应爻 | 应不能替代一切有明确亲属关系的对象 |
| 文书、合同、学业、房屋、长辈 | 父母 | 职位录用与合同到手可分别观察官鬼、父母 |
| 职位、任职、职务 | 官鬼 | 同一六亲在不同主题中不固定吉凶 |
| 财物、收益、回款 | 妻财 | 资金来源、竞争损耗须另看原神与忌神 |
| 子女、产出、解忧 | 子孙 | 求职中不能照搬“子孙就是好结果” |
| 同辈、竞争、分利 | 兄弟 | 是否阻碍须结合所问主题及实际生克 |

感情问题先确认角色和所问关系，不能只凭性别机械分配夫妻六亲。问自己或他人健康时，
先按世爻或该人的亲属关系定位对象；官鬼可作为病患线索，不能把所有病占都改为官鬼用神，
也不能从卦推定病名、停药或治疗效果。

列出所有与问题相关的本卦候选：爻位、六亲、持世应、明动静、月日扶克、空破及动变。
说明主用、辅助观察和选择理由，保留反证。

### 两现、多现（Y2）

有明确身份或对象线索时先据此区分；没有时，比较旺衰、动静、空破、受伤和世应联系，
给出主次方案或分别推演，不仅因“旺”就删掉另一候选。《两现章》列出古法择旺择动，
也保留空破爻决定应期的反例，因此本 Skill 不设“永远选旺爻／动爻”的固定排序。
成败的主要依据与应期的触发爻可以不同，但必须分别解释，不许事后换用神迎合结果。

### 不现与伏藏（Y3）

1. 先确认本卦确实没有相关六亲；动爻实际化出的相关六亲是变化线索，不能称为本卦已显。
2. 按本卦宫五行核对月日是否提供该用神的参照，明确称“月日为用”的推断，不能伪造爻位。
3. 检查 JSON 中本宫首卦所配的 `origin.fushen`；同位 `origin` 是飞神。
   列出伏神自身月日旺衰、空破，以及飞生伏、飞克伏、伏生飞或伏克飞。
4. 飞神受冲克、空破或衰弱可能提供引出条件；仍须伏神自身有生扶和作用条件。
   飞神空不等于伏神立即得出，伏神不现也不等于事情必败。

不得去其他宫、互卦或静爻 `variant` 随意找一个有利的用神。本书对伏神也有不同意见，
本 Skill 保留飞伏分析且默认复用原卦；不能把“不复摇”称为野鹤原书的禁令。

## 2. 月日、旺衰与空破（M1–M4）

五行相生：木→火→土→金→水→木；相克：木→土→水→火→金→木。
六冲：子午、丑未、寅申、卯酉、辰戌、巳亥。
六合：子丑、寅亥、卯戌、辰酉、巳申、午未。

逐项记录支持与制约，不把冲、合、生、克简单相加为吉凶分数：

| 编号 | 判据 | 条件与反例 |
| --- | --- | --- |
| M1 月日 | 比较用神及相关爻与 `yuejian`、`richen` 的五行生克、临值、冲合 | 月日结论相反时同时保留；月令休囚但日辰、动爻扶助，不能直接断无用 |
| M2 月破 | 爻支与月建相冲 | 月破是当前制约；动、变、受扶之爻须检查出月、填实、逢合，不能一律删去其作用 |
| M3 日冲 | 静爻旺相且有支持，受日冲可按暗动考察；静爻休囚无助受冲，按日破考察 | 旺衰有争议就列两种解释；不是所有日冲都是暗动。明动受日冲另查有气与受伤，不一律冲散 |
| M4 旬空 | 爻支属于日柱的 `kongwang` | 区分有气待时与衰弱受制；旬内受限、出旬、填实、冲空须结合原局。空不自动等于零作用，冲空也不保证成事 |

旺衰依据须可追溯至具体月日和爻，不得先称“旺”再用暗动证明其旺。
全卦没有明动时仍先检查 M3，且旺相静爻在本方法中并非完全不能生克；不能直接断
“稳定、不会变化”。暗动是规则推断，不改变 `is_changed`，也不产生变爻。
六合只先记关系，再讨论合助、牵制或待冲；不能见合便断成功或自动合化。

## 3. 原神、忌神与作用条件（G1）

以**已选择用神的五行**为基准：生用为原神（元神），克用为忌神，克原神并生忌神者
为仇神。这与以卦宫装出的六亲是两层关系，不可混为一谈。例如木为用时，水为原、金为忌、
土为仇；不是所有盘的子孙都永远是原神。

找到相应爻只说明关系存在，还须检查能否作用：月日是否支持、明动或暗动、空破、
以及动而化回头生克、进退、墓绝的制约。原神受制不能直接计作有力生用；忌神受制
也不能直接当作已经消失。原忌同动时核对是否形成连续相生或制约，勿把每条克单独累加。

## 4. 动爻与变爻的作用范围（D1）

按《动变生克冲合章》处理：

- 本卦动爻可以作用于本卦相关爻；先核对它自身的有效性。
- 变爻只生克冲合**本位动爻**。本位回头受生或受克，才进一步影响该动爻的作用能力。
  不把变爻当作独立第七爻横向生克其他本卦爻。
- 月日可作用于本、变、飞、伏；其他卦爻不跨位去“救”变爻，也不反向克伤日月。
- `variant` 的六亲以**本卦宫**为基准，不能另按变卦宫重装来解释此盘。
- 静爻的 `variant` 只是完整变卦同位信息，不能作为该静爻的化出结果。

例如本位酉金动化巳火，可讨论巳火回头克酉金；不能因这处巳火再声称它去克另一个
申金静爻。若讨论整卦变化结构，应单列象意，不能借此绕过作用范围。

单动也要复核用神与月日；多动先整理与用神、世应直接相关的链条。不能因一爻独动、
五动一静或全动就抛弃用神，套用另一套卦辞爻辞占法。

## 5. 进退、墓绝与反伏（D2–D4）

**D2 进退**只看明动本爻到其变爻的地支配对。按本次核对文本的进神为
亥→子、寅→卯、巳→午、申→酉、丑→辰、辰→未、未→戌，反向为退。
所核转录未列“戌丑”配对，采用其他版本时须先核实，不凭记忆补入。化进退仍看用、原、忌角色与
空破的兑现条件；忌神化进不能说成普遍利好，同五行变化也不全是进退。

**D3 墓绝**按该书五行口径核对，不混用八字十干阴阳顺逆长生表：

| 五行 | 长生 | 旺 | 墓 | 绝 |
| --- | --- | --- | --- | --- |
| 木 | 亥 | 卯 | 未 | 申 |
| 火 | 寅 | 午 | 戌 | 亥 |
| 金 | 巳 | 酉 | 丑 | 寅 |
| 水、土 | 申 | 子 | 辰 | 巳 |

土随水是本书采用的口径，并非流派共识。是否实际入墓、受绝要结合旺衰和生克；
例如弱金受巳火克，不得只因表中“金长生于巳”断为受生；旺土遇巳火亦不能仅按绝地断凶。

**D4 反吟伏吟**分别标明是卦／内外卦结构，还是实际动爻的本变地支关系。
爻变同支可察伏吟，爻变相冲可察反吟；仅一个配对不足以命名整卦，爻的阴阳翻转
也不等于地支反吟。静卦本变相同不是“动而伏吟”。只作为反复或受阻的辅助线索，
最终仍看用神有力与否，不能单凭卦型定成败。

## 6. 象意、应期与结论

六合、六冲、游魂、归魂和六神只在上述证据之后补充象意，不单独定吉凶。
青龙／朱雀／勾陈／腾蛇／白虎／玄武不能分别被直接翻译成成功、官司、拖延、欺骗、
灾难或第三者等现实事实；神煞同理。

问应期时应用[应期规则](liuyao-timing.md)，先判断事情及触发条件，再给用户时限内的
候选窗口；无法缩小时明确保留范围。不要从一组冲合编造精确日期。

回答保留三层：**盘面字段 → 指明条件的规则推断 → 现实可验证建议**。
列出至少一个对主要结论不利的证据或替代解释；没有反证时说明检索范围，不硬造。
证据冲突无法解决时给条件分支，不报伪精确概率，也不把经典案例的结果当成现实保证。
