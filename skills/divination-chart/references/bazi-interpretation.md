# 八字解读框架

## 1. 先核对口径

确认公历出生年月日时、性别和目标分析时间。提醒用户工具不做出生地、时区或真太阳时校正。若用户采用不同流派口径，先指出结果可能不同。

## 2. 从原局建立主线

按以下顺序读取：

1. 以日柱天干确定日主及阴阳五行。
2. 以月支为季节和月令核心，观察日主得令与否。
3. 检查四支藏干中的同类、印星是否构成通根和扶助。
4. 比较比劫、印星与食伤、财星、官杀的整体配置。
5. 查看天干地支的合、冲、刑、害、破、会及其涉及柱位。
6. 再参考十二长生、空亡、神煞、纳音等次级信息。

可使用 `heuristic_analysis.strength`、`ten_god` 和 `wuxing` 快速定位，但必须引用月令、四柱或藏干字段交叉验证。

## 3. 理解十神主题

十神是关系和功能语言，不是固定性格标签：

- 比肩、劫财：自主、同辈、竞争、资源分配。
- 食神、伤官：表达、技能、创造、产出、规则张力。
- 偏财、正财：资源、经营、回报、责任与现实配置。
- 七杀、正官：约束、职位、秩序、压力与责任。
- 偏印、正印：学习、支持、资格、保护与吸收。

结合十神落在哪一柱、是否透干、是否通根以及与月令的关系解释。不要仅按某十神分数高就给人格定论。

## 4. 使用喜忌与格局

- 把日主强弱作为平衡假设，而不是绝对等级。
- 把 `favorable_elements`、`useful_element` 等写成“库的补益倾向”。
- 检查候选格局的 `basis`；依据为空或薄弱时，不扩大解释。
- 不把五行直接机械映射为职业、颜色、方位、疾病或投资建议。

## 5. 叠加大运流年

1. 通过年龄和公历年份选中当前大运。
2. 比较大运干支对原局日主、喜忌和关键十神的作用。
3. 读取 `target_flow` 的流年、流月，观察是否触发原局关系事件或加强某类十神。
4. 区分长期命局、十年大运、年度/月份触发，避免把短期波动说成终身结论。

需要谈时间窗口时，以节气起点 `flow_months[].start_date` 为边界，不默认按公历每月 1 日切换。

## 6. 围绕问题输出

不要泛泛罗列全盘。根据用户问题选择证据：

- 事业：官杀、印星、食伤、当前大运流年及相关冲合。
- 财务：财星、食伤生财链、比劫竞争及现实现金流。
- 学业：印星、食伤、资格支持与阶段运势。
- 关系：日支、财官等传统观察与双方现实互动；避免性别刻板化。
- 健康：仅作五行文化象意，不诊断疾病，建议使用医学证据。

使用“字段事实 → 传统推断 → 现实条件”的写法。指出不同流派可能产生的解释分歧，避免宿命论和精确承诺。
